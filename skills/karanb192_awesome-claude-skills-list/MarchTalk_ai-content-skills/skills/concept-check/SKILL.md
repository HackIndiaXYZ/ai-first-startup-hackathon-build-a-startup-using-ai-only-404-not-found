# concept-check · 概念核验

## 核心判断

判断一个词/一个概念，有两层深度，别搞混：

- **A 层（贴身词语核验）**：这个词是不是万能空词——放哪个话题都通用、没有具体指向。三问自检就够了。
- **B 层（深度概念拆解）**：这个概念本身是不是没被想清楚——不同人说着同一个词其实各说各话，或者这个词的存在本身就在掩盖一处思考的空白。三问自检查不出这个，得走完整套拆解动作。

用户要"帮我拆一下这个概念""这个词到底什么意思""大家说的是一回事吗"，是要 B 层。只给一个"这是不是空词"的判断就收工 = 拿 A 层的活儿搪塞 B 层的要求，等于没拆。

## 什么时候调用

- **A 模式**：写文案时纠结某个形容词/状态词该不该用。
- **B 模式**：讨论中冒出一个模糊概念，想彻底想清楚它——「私域到底是什么」「大家说的复利是一回事吗」「这个词是不是包装」。有人要求"更高级""更有深度"的表达时，也先用 B 模式查清楚：是词的问题，还是判断本身就不够狠。

## 不要做什么

- 不要拿 A 模式的三问自检应付 B 模式的请求。用户要深度拆解，走完下面 B 模式全部步骤，不许中途喊停。
- 不要看到抽象词就无脑判空词。先过行业黑话豁免——赛道黑话（内化/私域/认知/流量/转化/涨粉/完播）对目标受众有具体指向，不该被换成生造的画面词。
- 不要用"炼语言"回应"要更高级"的要求。意象、警句、华丽词是装，不是深度；深度是判断链条能不能一层一层往下问"为什么"。
- 不要给伪概念找台阶。一个词经不起"去掉它、大白话还能不能说清楚"的检验，直接说它是包装，不装懂。
- 不要堆一堆正确的废话搪塞。每一步都要落到"这个概念具体错在哪/具体指什么"，说不出具体的就是没拆到位，回去重拆。

## A 模式：贴身词语核验（写文案时用）

### 步骤 1：三问自检

对每个可疑词过一遍：

1. 能让人立刻想到画面吗？
2. 能把你和别的做法区分开吗？
3. 能帮人排除掉某些做法吗？

三个都不能 → 空词，找替代。任一个能 → 保留。

**已验证的空词黑名单**：克制、质感、高级感、氛围感、调性、扛不住、撑不住、冷/冷清、边界感、体积感、立住/立得住。

**替换方向实例**（抽象状态词 → 画面动作词）：

| 空词 | 画面动作词 |
| --- | --- |
| 家还是冷的 | 进门像走进还没人住的样板间 |
| 撑不出"住进去这一档" | 业主住进去半年还是把家当酒店住 |
| 整面墙才压得住 | 整面墙看进眼里才有东西可看 |
| 态度立住了 | 不用说自己较真，这一句就够了 |

### 步骤 2：行业黑话豁免检查

判空词之前先问：**这是目标受众赛道本来就用的词吗？**

- 是（内化、私域、认知、思维、流量、转化、涨粉、完播这类自媒体/商业黑话，受众天天在用、听得懂、用得上）→ 正常用，不用换成画面词。硬凹一个生造的具象比喻（比如把"内化"换成"身体不疼"），反而显得搞笑，不像真人会说的话。
- 不是（放哪个赛道都通用、没有行业指向）→ 走步骤 1 三问自检。

**判断顺序：先问是不是行业词，不是才查空词三问**，顺序反了会把有效行话误杀。

## B 模式：深度概念拆解（六步走完；要写成内容再补步骤 7 落地校准）

### 步骤 1：使用场景对比

这个词在不同人嘴里是不是一个意思？逐个列：

| 谁在说 | 说的时候具体指什么 | 和别人说的一样吗 |
| --- | --- | --- |
| {使用者 1} | {含义 1，要具体到行为/结果，不能停在同义词替换} | |
| {使用者 2} | {含义 2} | |

同一个词几种人几种含义 → 各说各话，这本身就是问题所在：讨论下去之前得先钉死在说哪一种。

**专家视角补充**：除了列真实认识的人怎么用这个词，主动代入 1-2 个和这个概念最相关的专家视角——根据概念所属领域动态选，不是固定人选（涉及经济规律代入经济学视角，涉及心理动机代入心理学视角，涉及具体行业代入该行业老手视角）。把这个视角下的理解直接补进对比表的一行，不单开一段。

### 步骤 2：概念还原

追这个概念到它的源头：

- **原始语境**：这个词/说法最初是在什么场景下被用出来的？描述的是什么具体的事？
- **不变核心**：剥掉场景，它唯一不变的意思是什么？
- **搬进现在这个场景后，哪里被扭曲了**：原本描述 A 类现象的词，现在被拿来描述 B 类现象，中间悄悄换掉的假设是什么？
- **适用边界**：什么情况下用这个词是准的，什么情况下用是滥用？

### 步骤 3：假设检查（戳伪概念最狠的一刀）

这个概念是不是偷偷预设了一个**并不存在的客观答案**？

- 它是不是假设"有一个正确解，只要找到/设计出来就行"——但实际上这事没有客观正确解，只有当事人的主观判断，不同人给出的答案本来就该不一样？
- 它是不是假设"可以被自上而下设计出来"——但实际上这东西是从大量具体实践里自然长出来的，没人能画图纸把它设计出来？
- 如果这两条命中一条，这个概念大概率是个**伪概念**：它给人一种"只要想明白定义就能解决问题"的错觉，实际上唯一的解法是去真做、去试。

**怀疑论者视角（固定代入）**：假设有一个对这个概念完全不买账的人站在对面，他会怎么问、怎么戳这个预设？把他的质疑直接当成假设检查的输入，不用真写成对话——目的是逼出你自己可能没想到的那个漏洞。

**兜底：两条都不命中时别直接放行。** 这两条是最常见的两种假设漏洞，不是全部。两条都没命中，不等于这个概念没问题，只是没问题类型不在这两条里——退一步换个问法接着查：这个概念是不是在悄悄替换一个更朴素的说法（比如把"大家做法不一样"包装成"没有护城河"）？是不是把一个只能靠反复试错才能验证的判断，说得像是能一次性想清楚的定论？如果这两问也都答不上来漏洞在哪，才算真的没查出问题，往下走步骤4。

### 步骤 4：行动与结果检验

这个概念是在描述一个真实发生的行动/结果，还是在**替代**行动——让人误以为"把这个概念想清楚"本身就等于把事情做完了？

- 描述行动：概念只是给已经发生/正在发生的具体动作起了个名字，去掉概念，事情该怎么做还是怎么做。
- 替代行动：概念本身变成了一个可以停留、可以反复咀嚼的目的地——想清楚这个概念，人会觉得"我已经往前走了一步"，但实际上什么都没做，行动完全没发生。

再问一句：这个概念给出的判断，能不能被外部真实可见的结果验证（成交、留存、复购、转发、粉丝反馈这些具体、能摆出来的东西）？

- 能验证 → 概念站得住，可以拿结果去反复校准。
- 说不清要看哪个指标才算验证过 → 这个概念大概率是自说自话的空转命题，听起来对，但没人能拿出证据证伪它，也没人能拿出证据证实它。

**和步骤 3 的分工**：步骤 3 查"是不是预设了不存在的答案"，这一步查"这个概念到底能不能落到行动和结果上"。两步命中一个都该警惕，两步都命中，这个概念基本可以判死刑。

### 步骤 5：去词测试

把这个词从句子里拿掉，用大白话能不能说清同一件事？

- 能 → 这个词只是包装，不影响理解，不用纠结。
- 不能 → 说明这个词在替你掩盖一处没想清楚的地方，得先用大白话把那个空白填上，再决定这个词还要不要用。

### 步骤 6：问题类型判断

这个概念背后的真问题，能不能靠一段文字回答完？

- **能**：写清楚就完了，是个信息缺口，不是认知缺口。
- **不能**：不管答案写多细，都得真去做、去试错、拿到反馈才知道对不对——大部分让人纠结的商业困惑其实是这一类，只是被包装成了"该有个标准答案"的样子，一直在等一个说不出来的答案，其实该做的是去试。

### 步骤 7：落地校准（只在"拆完要用来写内容"时补，纯粹想清楚概念本身可以跳过）

概念到步骤 6 已经想透了，但离能直接写成稿还差最后一跳——把判断钉到具体赛道上，别停在正确但通用的分析层：

- **戳哪类受众**：这条判断最容易让哪一类具体受众觉得"这人看穿了我没看穿的东西"？说不出具体是哪一类，说明判断还停在通用层，没落地。
- **案例锚定（先判断内容类型，别无差别硬卡）**：观点/认知/思考/人设型——案例可有可无，满分标准是判断够不够狠、视角独不独特，硬塞案例反而稀释锋利度，这类别把案例当门槛。信任/成交型——真实案例能加分（建信任），禁用名人/编造案例，只能用真实接触过的客户案例；说不出具体案例，只说明这条还没准备好做成交型内容，不影响拿去做观点型内容。
- **查重**：这条判断有没有撞上你自己已经发过的命题？（对照你自己的已发内容清单）撞了就不是新判断，是同一个判断换了张皮。

```
# 概念拆解：{概念名称}

## 大家以为它是什么
{这个概念通常被怎么理解}

## 不同人嘴里是不是一回事
{步骤 1 的对比表 + 一句话判断：一致还是各说各话}

## 概念还原
- 原始语境：{...}
- 不变核心：{...}
- 现在这个场景里被扭曲了什么：{...}
- 适用边界：{什么时候用它是准的，什么时候是滥用}

## 是不是伪概念
{步骤 3 假设检查的结论：预设了不存在的客观答案吗/预设了能被设计出来吗}

## 是描述行动，还是替代了行动
{步骤 4 结论：能不能被结果验证，是不是空转命题}

## 去掉这个词，大白话怎么说
{步骤 5 结果}

## 这事能靠文字回答完，还是只能靠做出来
{步骤 6 结论}

## 一句话
{把上面全部压成一句最直给的判断}

## 落地校准（仅在要写成内容时补）
- 戳哪类受众：{...}
- 案例锚定：{先判断类型；观点/认知型可省，信任/成交型才需要真实案例，禁用名人/编造案例}

```

A 模式（贴身词语核验）输出更短：

```
{词}：{行业黑话，保留 / 空词，需替换}
判断依据：{三问结果 / 豁免检查结果}
{需要替换时给 2-3 个画面动作词候选}
```
