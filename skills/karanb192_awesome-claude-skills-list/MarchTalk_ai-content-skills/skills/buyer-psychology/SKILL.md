# buyer-psychology · 商业心理与购买阻力

## 什么时候调用

- 内容任务进入"为什么用户付费"环节。
- 内容数据好但不出单，需要从流量逻辑切换到成交逻辑。
- 用户提到价格、定价、利润、付费阻力、咨询拖延。
- 选题阶段判断一个角度有没有商业落点。
- 诊断阶段判断账号是不是只在博流量、漏掉了成交。
- 内容已经写出来，但读完觉得"用户看了不会动"。
- 咨询多但不成交，或者评论热但私信少。
- 需要写"戳一下"的开头、悬念、反问。
- 处理"用户说贵""我考虑一下""问了一圈"这类典型场景。

## 不要做什么

- 不要用学院派术语（赋能、闭环、势能、降维打击、底层逻辑、价值链、护城位）。
- 不要写成心理学论文（不要"马斯洛""峰终""认知失调"这种词）。
- 不要把商业拆解写成漂亮报告或咨询 PPT。
- 不要假设账号主已经懂自己的产品价值，多数人讲不清楚自己卖的是什么。
- 不要把"流量内容"和"成交内容"混着算。一条爆款不等于一笔订单。
- 不要用"提升转化率"这种没有具体动作的结论收尾。
- 不要替用户喊口号（"我们都知道用户怕被坑"），要具体到怕被谁、怕在哪个动作上被坑。
- 不要把所有用户简化成同一种心理，不同价位 / 不同决策角色 / 不同性别 / 不同城市的人心理不一样。
- 不要把心理刻画当成情绪渲染，重点是把不愿说出口的那句话写出来，不是煽情。
- 不要不管这条内容是给谁做的，默认套同一套人设语气去"戳人"。

## 工作流程

第一步：真伪需求

- 这个产品 / 服务有人为它真金白银付过钱吗？
- 付的是谁？付了多少？付的频率？复购了吗？
- 如果没有真实付费数据，把这一步标红，后面的所有结论都要打折。

第二步：翻译产品

- 用一句"用户能听懂"的话讲清楚这个产品在卖什么。
- 用户买的是结果、过程、承诺、还是身份感？
- 同一个产品对不同人群的"卖点"不一样，先锁人群再说卖点。

第三步：阻力盘点

用户不下单时，怕的是什么？必须落到下列六项之一：

- **钱**：买不起 / 觉得贵 / 担心买完不值。
- **风险**：买完不好用、不安全、出问题没人管、损失大于收益。
- **时间**：等不起、用不熟、学习成本太高。
- **信任**：不认识、没口碑、之前被坑过、看起来像骗子。
- **面子**：买完丢人、说不出口、家人不同意。
- **决策成本**：比来比去太累、决策链条太长、需要老婆 / 老板 / 合伙人拍板。

每条阻力要给具体场景（用户什么时候、在哪里、对谁、说什么话表达这种阻力）。

第三步半：把阻力翻译成心理独白（锁定阻力后必做）

阻力是经济理性层的分类，用户脑子里不会这么想——要把它翻译成具体的内心独白，才能落到表达：

1. **定位心理类型**：用户在这一刻的状态是下面哪一种（可以同时有多种，找"当下最强的那一种"）：
   - **不信**：不认识你 / 觉得是广告 / 怕被坑。
   - **不懂**：听不懂你在卖什么 / 比不出和别家的差别。
   - **不急**：现在不需要 / 等等再说 / 没到那个阶段。
   - **不敢**：怕选错 / 怕丢面子 / 怕家人反对 / 怕老板批评。
   - **不甘**：付一样的钱想要更多 / 觉得自己应该被特别对待。
   - **幻想**：希望有一个万能答案 / 希望一次性解决所有问题。
   - **拖延**：反复咨询、收藏、加好友，但不下单。
2. **还原内心独白**：把心理写成用户脑子里那句话，要满足三个条件——是用户视角不是创作者视角；是用户不会主动说出口的（说出口的多半是借口）；有具体场景和对象（"她半夜十二点对着购物车反复加了又删"，不是"她很犹豫"）。
3. **找锚点**：让用户从"不会动"变成"被戳一下"，靠哪个锚点？
   - **熟悉感**：你说的事我经历过 / 我家人就这样。
   - **认同感**：原来不是只有我这么想 / 这话替我说出来了。
   - **被看见**：你居然懂我没说出口的那部分。
   - **羞耻 / 愧疚**：我之前那么想是错的 / 我之前那么做亏待了自己 / 家人。
   - **解脱**：原来不用那么累 / 不用买那么贵也行。
   - **警告**：再不动可能就来不及了 / 错过这次会后悔。
   锚点和心理类型要匹配（"不信"的用户用警告无效，要先用熟悉感破冰）。
4. **落到表达**：把锚点翻译成具体的一句话、一个场景、一个动作。不要写"戳到她的愧疚感"，要写"那天她加班到十一点，孩子说妈妈你是不是不要我了"。

第四步：内容定位

判断当下这条内容的角色：

- **流量内容**：让陌生人刷到 / 记住 / 关注。
- **信任内容**：让看过的人觉得"这家懂行 / 不忽悠"。
- **成交内容**：让信任过的人推一把就下单。

三类内容写法不同，不能用同一套模板。

第五步：商业落点

每条结论必须翻译成具体动作 + 具体表达。不要写"提升信任"，要写"评论区固定回复一条价格说明"；不要写"戳到用户痛点"，要写第三步半落到表达那句具体的话或画面。

## 输出格式

```
## 真假需求
真实付费证据：（订单 / 案例 / 价格区间 / 复购频率）
判定：真 / 假 / 数据不足

## 产品翻译
用户能听懂的一句话：「____」
卖点对应的人群：「____」

## 最大购买阻力
（钱 / 风险 / 时间 / 信任 / 面子 / 决策成本）中具体哪一项
场景：用户在 ____ 情况下，对 ____ 说 ____

## 心理翻译
当下最强的心理类型：（不信 / 不懂 / 不急 / 不敢 / 不甘 / 幻想 / 拖延）
不会说出口的那句话：「____」（用户视角的内心独白，带场景）
锚点：（熟悉感 / 认同感 / 被看见 / 羞耻 / 解脱 / 警告）

## 这条内容的角色
流量 / 信任 / 成交

## 商业落点（具体动作 + 具体表达）
- 动作 1：____
- 表达：一句话 / 一个场景 / 一个动作的具体写法：____
```

## 质检标准

- 落点是钱、风险、时间、信任、结果、代价中的具体一项，没有"价值""势能""赋能"这种抽象词。
- 区分了流量内容和成交内容，没有混淆。
- 没有用咨询术语和学院派词汇，也没有用心理学术语装专业。
- 用户视角而不是老板视角（描述用户怎么想、怎么犹豫，而不是描述老板有多想卖）。
- 内心独白有具体场景、具体人、具体动作，不是抽象情绪词。
- 锚点和心理类型匹配，没有用警告去戳"不信"的人。
- 每条结论可以对应到一个明天就能做的具体动作，或一句具体的话 / 一个具体的画面。
- 真伪需求那一步如果没有付费证据，结论已经主动打折。
- 没有不管账号主是谁就默认套用同一套语气和站位。
